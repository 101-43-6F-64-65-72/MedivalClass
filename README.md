# MedivalClass - Virtual Room & Multiplayer Game

A real-time multiplayer virtual room application built with **Next.js**, **Supabase Realtime**, and **HTML5 Canvas**.

## Features

- 🎮 Real-time multiplayer movement & player tracking
- 🏫 Interactive Virtual Room with collision detection
- 📊 Interactive Presentation Screen inside the room
- ⚡ Powered by Supabase Realtime Channels

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
